# Job Ready

An AI-powered career development platform designed to help you build professional resumes, generate tailored cover letters, and prepare for interviews with industry-specific insights.

## Features

- **AI Resume Builder**: Create ATS-friendly resumes tailored to your industry.
- **Cover Letter Generator**: Generate professional cover letters for specific job applications.
- **Interview Preparation**: Practice with AI-generated questions based on your experience and industry.
- **Industry Insights**: Stay updated with the latest trends and salary ranges in your field.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/)
- **Authentication**: [Clerk](https://clerk.com/)
- **Database**: [PostgreSQL](https://www.postgresql.org/) with [Prisma ORM](https://www.prisma.io/)
- **AI**: [Google Gemini AI](https://aistudio.google.com/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Background Jobs**: [Inngest](https://www.inngest.com/)

## Getting Started

1.  Clone the repository.
2.  Install dependencies: `npm install`
3.  Set up environment variables in `.env`.
4.  Run the development server: `npm run dev`
5.  Generate Prisma client: `npx prisma generate`
